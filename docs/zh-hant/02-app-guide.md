# 2. 桌面 App 操作指南

[← 回到目錄](README.md)

本章以繁體中文介面為準，括號內附英文原文，方便對照英文文件或 Issue。

## 2.1 標題列

| 元件 | 功能 |
|------|------|
| 首頁（Home） | 回到「你想製作什麼？」 |
| 簡易 / 進階（Simple / Advanced） | 切換兩種介面，引擎相同 |
| 淨室 / 深度（Clean room / Deep） | 切換研究模式（見下方 2.4） |
| AI 選單 | 「由哪個 AI 回答你的問題」；尚未設定時顯示「設定 AI 助手…」 |
| 設定（Settings） | 開啟設定視窗 |

## 2.2 簡易模式

### 首頁：你想製作什麼？

1. 選擇類型：**網站**、**應用程式** 或 **遊戲**。
2. 輸入目標：網址、App 位置或遊戲資料夾；做全新作品時可以留空。
3. 選擇 **淨室** 或 **深度**。
4. 說出需求。寫法建議：

| 想要 | 範例需求 |
|------|----------|
| 完整重現 | `重現這個網站` |
| 指定技術 | `用 Next.js 重現這個網站`、`用 Godot 重現這款遊戲的玩法` |
| 局部修改 | `重現這個網站，但把配色改成綠色系` |
| 全新創作 | `做一個番茄鐘桌面 App，用 Rust` |

> 你的話優先於預設：需求中提到的語言、框架或引擎一定會被採用；沒提到才用合理的預設。

5. （選用）加入參考圖片，App 會以「符合我的圖片」為目標修正。
6. 按 **開始**。也可以按「選擇資料夾…」讓專案從你指定的資料夾開始。

### 只檢視內部（Just look inside）

只想了解某個軟體、不打算建置時使用。它會開啟目標讓你直接提問，需要 **深度** 模式。

### 專案頁

| 區塊 | 說明 |
|------|------|
| 步驟列 | 研究 → 建置 → 檢查 → 就緒 |
| 動態 | Agent 正在做什麼的白話描述 |
| 計畫 | 可拖曳調整高度；顯示已完成的步驟數 |
| 問題卡片 | Agent 需要你決定的事，點選按鈕回答 |
| 核准卡片 | 允許一次 / 此專案中一律允許 / 不允許 |
| 相似度 | 每次檢查與原作的接近程度，以及還不相符的項目 |
| 底部輸入框 | 隨時輸入修改要求；建置中輸入的內容會在 Agent 下一次動作後交給它 |
| 動作按鈕 | 開啟資料夾、執行遊戲、預覽網站、暫停、停止、重試 |

每則訊息與答案都有「複製」按鈕。

### 暫停、停止與重試

- **暫停**：保留目前進度，稍後繼續。
- **停止**：結束這次執行。
- **重試**：從專案記錄的狀態接著做，不會從頭重新研究。

## 2.3 進階模式（工作台）

| 面板 | 內容 |
|------|------|
| 目標清單 | 已開啟的檔案、App、網站 |
| 函式 / 字串 | 從程式中找出的函式與字串，可篩選 |
| 檢視區 | 虛擬 C 碼（pseudo-C）、反組譯、十六進位（可「跳到位移 0x…」）、呼叫圖 |
| 檢查器（Inspector） | 選取項目的詳細資訊 |
| 證據紀錄（Evidence ledger） | 每個發現都附「有多確定」的信心程度 |
| 待確認事項（Unknowns） | 尚未解答的問題 |
| 工作（Jobs） | 背景執行中的工作；可「清除已完成項目」 |
| 代理程式主控台 | 與 AI 對話；在任何項目上可選「詢問代理程式」 |

### 命令面板

按 **Ctrl+K**（Windows / Linux）或 **⌘K**（macOS）開啟。可以用**繁體中文工具名稱、英文名稱或工具 ID** 搜尋全部 320 個工具，例如輸入「字串」、`strings` 或 `native_strings_list`。

### 斜線指令

在代理程式輸入框打 `/` 會列出可用的指令，例如 `/btw` 可以在 Agent 工作中途補充說明。

## 2.4 淨室與深度：實際差異

| 動作 | 淨室 | 深度 |
|------|------|------|
| 網站截圖、可見文字、版面、色彩、字型 | ✅ | ✅ |
| 展開選單、以訪客身分瀏覽 | ✅ | ✅ |
| App 視窗截圖（需你允許） | ✅ | ✅ |
| 讀取網頁 JavaScript、監看首頁載入 | ❌ | ✅ |
| 讀取程式碼、反組譯、反編譯 | ❌ | ✅ |
| 解包遊戲資源檔 | ❌ | ✅ |
| 使用 Ghidra | ❌ | ✅（有安裝時） |

在淨室下呼叫會「看內部」的工具時，App 會拒絕並說明如何開啟深度模式。

## 2.5 設定（Settings）

設定視窗有五個分頁：

### 一般（General）

| 項目 | 說明 |
|------|------|
| 模式 | 簡易或進階介面 |
| 語言 | 跟隨系統 / English / Français / 日本語 / Deutsch / Čeština / 한국어 / Русский / 简体中文 / **繁體中文** |
| 新專案儲存位置 | 預設 `文件/Craft Anything`（`Documents/Craft Anything`） |
| 同時列出這些位置的專案 | 加入其他資料夾；移除只會從清單拿掉，不刪檔案 |
| 你選的資料夾已有檔案時 | 記住「它就是 App 本身（直接修改）」或「起始素材（App 建在旁邊的 `app/`）」 |
| 佈景主題 | 跟隨系統 / 淺色 / 深色 |
| 再次顯示歡迎畫面 | 重新看一次首次啟動導覽 |

### 引擎（Engines）

管理外部引擎：Ghidra（資料夾、Ghidra 記憶體用量）、Java 執行階段、adb、Frida、JADX、Apktool、Unity / Unreal / Godot 等。
下載的檔案在使用前都會先核對發布者提供的總和檢查碼。

### AI

新增、偵測、測試 AI 後端，選擇「用它建置」的後端、模型與思考深度。詳見 [AI 與編碼 Agent 設定](03-ai-setup.md)。

### 建置（Builds）

| 項目 | 說明 |
|------|------|
| 自動模式 | 「繼續執行，無須詢問」或「執行前先詢問」。自動模式下 Agent 仍**不會**刪除專案外的檔案、修改系統設定或發布任何東西 |
| 修正輪數（Refining rounds） | 首次建置後最多進行幾輪修正（App 預設最多 6 輪） |
| 達到要求（Good enough） | 相似度達到多少就停止修正 |
| 網站頁面 | 除了你給的網址外，還要研究與比對網站的其他幾頁 |
| 符合我的圖片 | App 與遊戲：持續修正直到與你的圖片夠像；關閉時只回報相似度 |
| 同時建置數量 | 同時可建置幾個專案，多的排隊 |
| 生成美術（遊戲） | 新專案預算：生成圖片 / 3D 模型等付費素材的上限；圖片模型：用哪個模型生成圖片與材質 |

### 外掛（Plugins）

新增 MCP 伺服器外掛，或（在啟用 `wasm-plugins` 的版本中）WASM 元件外掛。範例見 `examples/wasm-plugin-*`。

## 2.6 生成圖片與 3D 模型（選用）

遊戲專案可讓建置助手生成圖片與 3D 模型，需要**你自己的 fal.ai 金鑰**，費用從專案預算中扣除。
預設關閉；CLI 用 `--generate-assets` 開啟，之後可用 `project-assets-allow` 調整。
