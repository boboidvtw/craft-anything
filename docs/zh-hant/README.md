# Craft Anything 繁體中文使用說明

> 這份說明以繁體中文（台灣用語）撰寫，對象是想實際使用 Craft Anything 的人。
> 內容根據英文原始文件與程式碼整理；若與英文文件有出入，以英文版（[README.md](../../README.md)、`docs/*.md`）為準。

## 一句話介紹

**Craft Anything 讓你指定一個網站、App 或遊戲，它會先「研究」原作，再交給 AI 編碼 Agent「建置」出你自己的版本，接著「檢查」兩者的差異並反覆修正，直到夠接近為止。**

它同時是：

| 形式 | 用途 |
|------|------|
| 桌面 App（egui） | 一般使用者：選目標、說需求、按「開始」 |
| CLI（`craft-anything-cli`） | 開發者與腳本：所有功能都能從終端機執行 |
| MCP 伺服器（`craft-anything-cli mcp`） | 讓 Claude Code、Cursor、Codex 等 Agent 直接呼叫 320 個工具 |
| 瀏覽器檢視器（WebAssembly） | 在瀏覽器中判斷檔案類型，檔案不離開瀏覽器 |

## 核心觀念速覽

### 四個步驟

```
研究（Study） → 建置（Build） → 檢查（Check） → 就緒（Ready）
                     ↑                │
                     └── 不夠像就修正 ─┘
```

1. **研究**：用真正的檢查工具觀察原作（網頁截圖、版面量測、程式結構…）。
2. **建置**：編碼 Agent（預設是你電腦上的 Claude Code）在新的專案資料夾中寫程式。
3. **檢查**：把成果與原作比對，例如網頁會在三種螢幕寬度下比較相似度。
4. **就緒**：你可以開啟、遊玩或預覽成果；不滿意就直接打字要求修改。

### 兩種模式：淨室 vs 深度

這是使用前**最重要**的觀念。

| | 淨室（Clean room，預設） | 深度（Deep） |
|---|---|---|
| 會不會讀原作內部 | **不會**：不讀程式碼、檔案、網頁原始碼 | **會**：使用所有工具 |
| 依據什麼 | 看得到的東西：截圖、可見文字、版面、顏色、字型、你提供的圖片 | 加上程式碼、反組譯、反編譯、JavaScript 原始碼、Ghidra（若有安裝） |
| 適合 | 重現「外觀與行為」，降低著作權風險 | 研究自己擁有或獲准分析的軟體，供私人使用 |
| 切換 | 標題列或「設定」；CLI 加 `--clean-room` | 標題列或「設定」；CLI 加 `--deep`；或 `settings_set deep_mode true` |

> **注意：淨室不是沙盒。** 它只規範 Craft Anything 自己提供或拒絕哪些工具，不會隔離你的電腦。
> 你啟動的編碼 Agent 仍以你的身分執行，能做什麼取決於 Agent 本身的權限設定。

### 兩種介面：簡易 vs 進階

- **簡易模式**：「你想製作什麼？」→ 選類型 → 描述 → 開始。適合所有人。
- **進階模式**：完整逆向工程工作台（函式、字串、虛擬 C 碼、反組譯、十六進位、呼叫圖、證據帳本、Agent 主控台）。按 `Ctrl/Cmd+K` 開啟命令面板搜尋任何工具。

兩者使用的是同一個引擎，可以隨時切換。

## 名詞對照表

App 介面與本說明使用以下譯名（與 `crates/ui-egui/src/i18n/zh-hant.tsv` 一致）：

| 英文 | 繁體中文 | 說明 |
|------|----------|------|
| Clean room | 淨室 | 不讀取原作內部的模式 |
| Deep | 深度 | 使用所有工具的模式 |
| Study / Build / Check / Ready | 研究 / 建置 / 檢查 / 就緒 | 四個步驟 |
| Simple / Advanced | 簡易 / 進階 | 兩種介面 |
| Project | 專案 | 一個「要做的東西」及其資料夾 |
| Target | 目標 | 被研究的網站、App、檔案或遊戲 |
| Evidence | 證據 | 每個分析結果都是一筆附信心程度的證據紀錄 |
| Unknowns | 待確認事項 | 尚未解答的問題 |
| Builder / Built by | 建置助手 | 負責寫程式的編碼 Agent |
| Backend | 後端 | 一個 AI 來源（Claude Code、API 金鑰等） |
| Toolset | 工具集 | 依領域分組的工具 |
| Approval | 核准 | Agent 要做規則以外的事時，跳出的詢問卡片 |
| Inbox | 收件匣 | 存放待你回答之問題的資料夾 |
| Plugin | 外掛 | MCP 伺服器或 WASM 元件 |

## 負責任使用

- 只對**你擁有或獲准檢查**的軟體使用。
- 它**不會**繞過 DRM、登入機制或反作弊系統。
- Agent 被指示不得複製標誌、照片或文字，除非你確認擁有權利。
- 建置過程中安裝相依套件（`npm install`、`cargo build`…）**會在你的電腦執行程式碼**；只對你信任的專案選「此專案中一律允許」。
